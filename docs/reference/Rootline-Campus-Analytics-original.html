Score methodology

Transparent and adjustable starter model

Rule-based · v1.0

The Student Success Score is a weighted composite index, not a prediction of a student's worth or a guaranteed outcome. It is intended to help staff decide where to offer support. Use validated institutional data, review the model with faculty, and never make high-impact decisions solely from this score.

Configured weights: Academic 30%, Attendance 20%, LMS engagement 15%, Engagement 10%, Placement readiness 15%, Skills 10%. Missing or invalid indicators are excluded and the remaining weights are renormalized. Placement readiness is included only for 4th Year students when a valid value is available; if no applicable indicators are valid, the score is N/A. This is a rule-based decision-support indicator, not a trained or validated prediction. Valid linked internal, attendance, LMS and fourth-year placement records take precedence over profile values; profile values are fallbacks when no valid source measure exists. Engagement and skills currently use profile indicators because their workspaces do not define a normalized 0–100 measure. Academic risk and placement readiness risk are shown as separate indicators with explicit thresholds.
